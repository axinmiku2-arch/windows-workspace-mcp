# Windows Workspace MCP · 本机工作区小助手

把**运行在云端、支持远程 MCP 的 AI 客户端**桥接到一台 Windows 电脑。AI 只看到你在本机选定并授权的工作区，不等于接管整个桌面。Windows 端提供可视化管理台，查看当前工作区、连接状态、待审批请求、文件收发及本机任务。

与早期仅可读的版本不同，这个分支以完整管理器和工作器为基础。出厂没有预填地址、账号、令牌、工作区或权限；安装自己配置的入口，不会迁移或替换旧版本的本机状态。

## 可以用来做什么

- 浏览目录、搜索文件或文本，读取和编辑 UTF-8 文本。修改前核对原文哈希，符合权限时备份。移动、改名、回收与恢复属于受工作区约束的独立操作；回收用的是应用私有回收区。
- 在支持的格式上做轻量预览；通过有效期有限的 HTTPS 地址双向传输文件原件，核对大小与 SHA-256。下载侧支持 Range 时可继续拉取；已落盘的文件不会因撤销授权而被删除。不要把签名地址发给无关人员。
- 执行预设的本机项目任务，例如 Git 状态或差异、Python 语法检查、运行项目的 Python/npm 测试或 npm 构建。是否能执行取决于本机依赖、权限和审批；**允许运行项目代码的任务并不等于提供任意 CMD/PowerShell**。
- 可以保存多套工作区配置，再切换当前授权的工作区。临时链接和旧请求适用各自的授权代次；切换工作区之前应先结束正在传的文件。

这不是远程桌面、不是通用远程命令终端，也不会自动提升为管理员。项目代码可产生副作用，请用标准 Windows 用户和最小范围工作区运行，不要给来源不明的项目批准构建或测试。

## 云端如何连进来

云端客户端必须能访问你的 HTTPS 地址。电脑无需在路由器上开放入站端口，可以选以下一条路：

- **个人试用首选：Tailscale Funnel。** Windows 上的 Tailscale 向外建立连接，把 Funnel 给你的 HTTPS 地址反向代理到仅监听本机回环的服务。Funnel 在公网可达，不是私有 tailnet；不要把公网可达误当成鉴权，也不要指望它有固定的大文件速度。
- **更可控：VPS + 你自己的域名。** HTTPS 在 VPS 终止，再通过由 Windows 主动建立的反向连接转到本机回环端口。域名本身不提速，取决于 VPS 选址、两端线路、并发策略和带宽。自行承担续证、更新、监控和鉴权责任。

见 [部署指南](docs/deployment.zh-CN.md)。只为具体客户端登记准确的回调地址，不要用通配地址。路径、账号、令牌和密钥留在使用者自己的机器上，不能进公共仓库。
